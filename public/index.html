  sum = sum + i

Validation

Verified Structural Rules

Every flowchart is evaluated by our core validator before pseudocode generation.

Single Start Node

Enforces exactly one entry point in the diagram, catching missing or duplicate start nodes.

Guaranteed Termination

Verifies the flowchart has at least one valid end node so execution terminates properly.

Two-Exit Decisions

Ensures every decision diamond has at least two outgoing edges for true and false branching.

No Orphan Nodes

Traverses the connection graph to ensure every box is fully reachable from the start node.

Referential Integrity

Confirms every directed arrow connects valid, known source and target diagram nodes.

Full Human Editing

Every detected box kind, text label, and connection can be inspected and edited in the editor.

Photo tips for best results — 3 common traps

1. Camera Angle

✓ Good
Straight-on angle

Hold camera flat and parallel to the paper.

✕ Avoid
Tilted / skewed angle

Avoid steep tilts that compress shapes.

2. Lighting & Shadows

✓ Good
Even, bright light

Clear, uniform light across all boxes.

✕ Avoid
Harsh shadows

Avoid phone shadows obscuring text.

3. Arrow Connections

✓ Good
Clean arrow paths

Arrows connect clearly without crossing.

✕ Avoid
Crossing lines

Avoid lines cutting through text boxes.
